# NAS Archive Native

تطبيق مكتبي محلي لأرشفة الوثائق الشخصية والرسمية على Windows، بواجهة عربية أولاً، ويعمل بدون Docker أو WSL أو خادم localhost.

## المعمارية الحالية

- Electron Desktop.
- SQLite مع WAL وFTS5 للبحث المحلي.
- تخزين ملفات أصلي داخل مجلد أرشفة محلي يحدده المستخدم من الإعدادات.
- OCR عربي/إنجليزي.
- تكامل NAPS2 / WIA للمسح الضوئي.
- IPC محلي معزول بين الواجهة وElectron Main.
- تحديثات تلقائية من GitHub Releases.

## سير العمل

1. مسح ضوئي أو استيراد ملف.
2. حفظ مؤقت في Staging مع معاينة قبل الأرشفة.
3. التحقق من الملف وكشف التكرار.
4. تحسين صورة الوثيقة عند الإمكان.
5. OCR واستخراج النص.
6. تحليل metadata واقتراح القيم.
7. إنشاء مسار الأرشيف المنطقي.
8. حفظ الأصل ونسخة الأرشيف وقاعدة البيانات.
9. إنشاء thumbnail.
10. مراجعة بشرية واعتماد الحقول.

## إدارة المستندات

يدعم النظام:

- Grid / Table / List.
- البحث والفلاتر.
- الأقسام: شخصي، الرنين، تناسق، NAS FM.
- أنواع المستندات والجهات وسياسات التخزين.
- Saved Views.
- Bulk actions.
- سلة مهملات واستعادة.
- محرر metadata.
- Smart Suggestions للحقول المتكررة.
- عارض PDF متعدد الصفحات.

## النسخ الاحتياطي والاستعادة

من داخل الإعدادات يمكن إنشاء نسخة احتياطية محلية تتضمن قاعدة البيانات وملفات الأرشيف. الاستعادة عملية صريحة وتتطلب تأكيداً لأنها تستبدل حالة الأرشيف الحالية.

راجع: `docs/backup.md`.

## مسار الأرشفة والمزامنة

من صفحة الإعدادات يجب تحديد مجلد الأرشفة المحلي على جهاز Windows أو قرص NAS متصل. يفحص التطبيق صلاحيات القراءة والكتابة قبل اعتماد المسار، ويطبق تغيير المسار بعد إعادة التشغيل لحماية قاعدة البيانات من النقل أثناء العمل.

توجد إعدادات Google Drive Sync كخيار صريح. لا يرفع التطبيق أي مستند تلقائياً؛ المزامنة تتطلب تفعيل المستخدم، إعداد مجلد Drive المستهدف، واعتماد الوثيقة للمزامنة.

## التحديثات

الإصدارات المثبتة تستخدم `electron-updater` مع GitHub Releases.

- فحص أول بعد بدء التطبيق.
- فحص دوري لاحق.
- تنزيل تلقائي.
- تثبيت عند إعادة التشغيل أو بطلب المستخدم بعد اكتمال التنزيل.

## الاختبارات والإصدار

الأوامر الأساسية:

```powershell
npm ci
npm test
npm run dist
```

الإصدار الرسمي لويندوز يتم عبر GitHub Actions عند إنشاء tag بصيغة `v*`. الـ workflow يتحقق من JavaScript regression tests وبناء ملف NSIS قبل نشر الـ Release.

## ملاحظات الهجرة

المستودع يحتفظ بمحرك هجرة لقراءة snapshots قديمة من Paperless-ngx ونقلها إلى SQLite المحلي. هذا **مسار هجرة فقط** وليس backend تشغيلياً للتطبيق الحالي.
